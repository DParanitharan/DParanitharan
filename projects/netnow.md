*Software Engineering Intern (Full-time)* · Sep 2025 – Dec 2025

- **Built a real-time email monitor** (Gemini API + SQL) that posts actionable **Slack** updates for leadership.
- Shipped **7 features and 9 full-stack bug fixes** in React and JavaScript.

## Stack
Python · Docker · OCR · Docling · Gemini API · Celery · Redis · Django · PostgreSQL · Gmail API · React · JavaScript
