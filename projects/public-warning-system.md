# Public Warning System Prototype

**CatalystxAI — NUS Entrepreneurship Society Hackathon** · Oct 2023

## Idea
An early-warning prototype for climate-vulnerable communities, built during a hackathon.

## Approach
- Built an **R-based public warning prototype** by aggregating **10+ datasets**.
- Pitched the concept to **3 judges** and **100+ students**.

## Stack
R · multi-dataset aggregation

## Outcome
A working proof-of-concept demonstrating how open data can drive timely public warnings.
